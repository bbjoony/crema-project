# 크레마 카르타 e-ink 리더기 재활용 프로젝트 개요

## 배경
- 공식 지원이 종료된 크레마 카르타(교보문고 이북리더기) 하드웨어를 보유 중
- 카르타G 롬(안드로이드 4.4.2)으로 업데이트되어 있어 아직 구동 가능한 상태
- 하드웨어를 폐기하지 않고 e-ink 디스플레이를 별도 용도로 재활용하고자 함
- 목표 용도: 캘린더 / 시계 정보를 상시 표시하는 e-ink 디스플레이

## 기기 사양 (확인된 사실)
- 기기: 크레마 카르타 (교보문고)
- 펌웨어: 카르타G 롬 (안드로이드 4.4.2)
- 저장매체: 샌디스크 16GB microSD 장착

## 방향성 결정 사항
- 기존에 존재하는 플러그인을 그대로 쓰는 대신, **KOReader용 Lua 플러그인을 처음부터 직접 작성**하는 방향으로 결정함
- e-ink 디스플레이를 시계/캘린더 용도로 활용한 기존 사례를 조사한 뒤 구체적인 설계로 진행하기로 함 (아직 미착수)

## 코드 저장소 관련
- 개인 토이 프로젝트이므로, 코드는 개인 GitHub 계정(`bbjoony`)에 저장 예정
- 업무용 계정과는 무관하게 별도 관리

## 다음 단계 (미착수, 논의만 된 상태)
1. e-ink 시계/캘린더 표시 관련 기존 KOReader 플러그인·프로젝트 사례 조사
2. 플러그인 기능 요구사항 정리 (표시할 정보, 갱신 주기, UI 레이아웃 등)
3. 카르타G 롬 상에서의 개발/디버깅 환경 확인 (개발자 옵션, ADB 접근 여부 등 미확인)
4. KOReader Lua 플러그인 개발 착수
