# 크레마 카르타 e-ink 재활용 프로젝트

지원이 종료된 교보문고 **크레마 카르타** e-ink 리더기를, 폐기하지 않고 **시계·캘린더 상시 표시용 e-ink 디스플레이**로 재활용하는 개인 토이 프로젝트입니다.

## 목표

e-ink 디스플레이에 시계 / 캘린더 정보를 상시 표시하는 **KOReader용 Lua 플러그인**을 직접 작성합니다.

## 기기 사양

| 항목 | 내용 |
|------|------|
| 기기 | 크레마 카르타 (교보문고) |
| 펌웨어 | 카르타G 롬 (안드로이드 4.4.2) |
| 저장매체 | 샌디스크 16GB microSD |

## 방향성

- 기존 플러그인을 그대로 쓰지 않고 **KOReader용 Lua 플러그인을 처음부터 직접 작성**
- e-ink 디스플레이를 시계/캘린더로 활용한 기존 사례를 조사한 뒤 구체 설계로 진행

## 진행 상황

현재 **초기 논의 단계** 입니다. 방향성만 정해졌고 코드는 아직 없습니다.

### 다음 단계

1. e-ink 시계/캘린더 표시 관련 기존 KOReader 플러그인·프로젝트 사례 조사
2. 플러그인 기능 요구사항 정리 (표시할 정보, 갱신 주기, UI 레이아웃 등)
3. 카르타G 롬 상의 개발/디버깅 환경 확인 (개발자 옵션, ADB 접근 여부 등)
4. KOReader Lua 플러그인 개발 착수
