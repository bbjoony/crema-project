# 크레마 카르타 e-ink 재활용 프로젝트

지원이 종료된 교보문고 **크레마 카르타** e-ink 리더기를, 폐기하지 않고 **시계·캘린더 상시 표시용 e-ink 디스플레이**로 재활용하는 개인 토이 프로젝트입니다.

## 목표

e-ink 디스플레이에 시계 / 캘린더 정보를 상시 표시하는 **KOReader용 Lua 플러그인**을 만듭니다.

## 기기 사양

| 항목 | 내용 |
|------|------|
| 기기 | 크레마 카르타 (교보문고) |
| 펌웨어 | 카르타G 롬 (안드로이드 4.4.2) |
| 저장매체 | 샌디스크 16GB microSD |

## 방향성

- [digitalclock.koplugin](https://github.com/DucNg/digitalclock.koplugin)(AGPL-3.0)을 **포크**해 카르타에 맞게 고칩니다 (2026-08-12 결정)
- 캘린더 소스를 외부에 두지 않는 **온디바이스 렌더링**. 상시 구동 서버를 딸리게 하지 않습니다
- **상시 USB 전원 연결**을 전제로 합니다. 배터리로는 24시간을 못 버팁니다 (실측)

> 처음에는 "기존 플러그인을 쓰지 않고 직접 작성"하는 방향이었으나, digitalclock 을 수정 없이 실기 구동해 본 결과 대부분을 그대로 쓸 수 있음이 확인되어 포크로 선회했습니다.

## 진행 상황

**실기 검증 단계.** 포크 반입 전이라 시계 코드는 아직 저장소에 없습니다.

- KOReader 설치 및 e-ink 실동작 확인 완료 — `EPD: freescale` 로 정식 지원되며 화면 플래시까지 확인
- 자체 플러그인 `cremaclock` 실기 구동 성공. adb·logcat 이 모두 막힌 기기라 **화면 표시가 유일한 로그 채널**이며, 이 플러그인이 그 역할을 맡습니다
- digitalclock 무수정 설치 → 정상 동작. 한글 날짜·레이아웃 여유 확인, 대신 배터리는 하루를 못 버팀

### 다음 단계

1. 포크 반입 — `LICENSE`(AGPL-3.0) 및 원저작자 표기 동반
2. 요구사항 확정 (표시 정보, 갱신 주기, 캘린더 소스, 레이아웃)
3. 수정 착수 — 날짜 어순 한국어화(`2026년 8월 12일 화요일`)가 첫 대상
4. 캘린더 기능 신규 작성 — digitalclock 에는 없는 부분
