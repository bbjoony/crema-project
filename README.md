# 크레마 카르타 e-ink 재활용 프로젝트

지원이 종료된 교보문고 **크레마 카르타** e-ink 리더기를, 폐기하지 않고 **시계·캘린더 상시 표시용 e-ink 디스플레이**로 재활용하는 개인 토이 프로젝트입니다.

## 목표

e-ink 디스플레이에 시계 / 캘린더 정보를 상시 표시하는 **KOReader용 Lua 플러그인**을 직접 작성합니다.

## 기기 사양

| 항목 | 내용 |
|------|------|
| 기기 | 크레마 카르타 (교보문고) |
| 펌웨어 | 카르타G 롬 (안드로이드 4.4.2) |
| 저장매체 | 샌디스크 16GB microSD |

## 방향성

- 기존 플러그인을 그대로 쓰지 않고 **KOReader용 Lua 플러그인을 처음부터 직접 작성**
- e-ink 디스플레이를 시계/캘린더로 활용한 기존 사례를 조사한 뒤 구체 설계로 진행

## 진행 상황

**사례 조사 완료.** 코드는 아직 없습니다.

조사 결과 가장 가까운 레퍼런스는 [dtdisplay.koplugin](https://github.com/kktse/dtdisplay.koplugin)(온디바이스 전체화면 시계)이며, 최대 리스크는 안드로이드 버전이 아니라 **카르타의 e-ink 리프레시 드라이버를 KOReader가 지원하는지 여부**로 확인됐습니다.

### 다음 단계

1. KOReader 설치 + e-ink 호환성 테스트 ← 최우선
2. 개발/디버깅 환경 확인 (개발자 옵션, ADB)
3. `dtdisplay.koplugin` 실기 구동으로 기준점 확보
4. 요구사항 확정 (표시 정보, 갱신 주기, 캘린더 소스, 레이아웃)
5. 플러그인 작성 착수
