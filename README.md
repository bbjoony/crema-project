# 크레마 카르타 e-ink 재활용 프로젝트

지원이 종료된 교보문고 **크레마 카르타** e-ink 리더기를, 폐기하지 않고 **상시 표시용 e-ink 디스플레이 시계**로 재활용하는 개인 토이 프로젝트입니다.

## 목표

e-ink 화면에 **시각 · 날짜 · 작은 이미지**를 상시 표시하는 **KOReader용 Lua 플러그인**을 만듭니다.

> 초기 구상에 있던 캘린더/일정 표시는 범위에서 뺐습니다 (2026-08-12). 남은 일이 기존 코드를 손보는 수준으로 줄었습니다.

## 기기 사양

| 항목 | 내용 |
|------|------|
| 기기 | 크레마 카르타 (교보문고) |
| 펌웨어 | 카르타G 롬 (안드로이드 4.4.2) |
| 저장매체 | 샌디스크 16GB microSD |

## 방향성

- [digitalclock.koplugin](https://github.com/DucNg/digitalclock.koplugin)(AGPL-3.0)을 **포크**해 카르타에 맞게 고쳤습니다 (2026-08-12 결정)
- 표시할 내용을 외부에서 받아 오지 않는 **온디바이스 렌더링**. 상시 구동 서버를 딸리게 하지 않습니다
- **상시 USB 전원 연결**을 전제로 합니다. 배터리로는 24시간을 못 버팁니다 (실측)

> 처음에는 "기존 플러그인을 쓰지 않고 직접 작성"하는 방향이었으나, digitalclock 을 수정 없이 실기 구동해 본 결과 대부분을 그대로 쓸 수 있음이 확인되어 포크로 선회했습니다.

## 진행 상황

**목표한 기능이 모두 동작합니다. 기기에서 상시 표시용으로 돌아가고 있습니다 (2026-09-07).**

- KOReader 설치 및 e-ink 실동작 확인 완료 — `EPD: freescale` 로 정식 지원되며 화면 플래시까지 확인
- 자체 플러그인 `cremaclock` 실기 구동 성공. adb·logcat 이 모두 막힌 기기라 **화면 표시가 유일한 로그 채널**이며, 이 플러그인이 그 역할을 맡습니다
- digitalclock 무수정 설치 → 정상 동작. 한글 날짜·레이아웃 여유 확인, 대신 배터리는 하루를 못 버팀
- **포크본 `cremadisplay` 실기 구동 성공.** 사전에 세워둔 확인 목록을 모두 통과했습니다:

| 확인 항목 | 결과 |
|---|---|
| 메뉴 등재 및 화면 표시 | 시각·날짜·이미지가 의도한 대로 그려집니다 |
| 날짜 어순 | `2026년 9월 7일 월요일` 로, 한국어 어순을 따릅니다 |
| 사용자 이미지 | 절대 경로로 `image.png` 를 찾아 작게 표시합니다 |
| **분 갱신 시 잔상** | 옛 숫자가 남지 않습니다. 가장 우려했던 항목이었습니다 |
| 밤샘 부분 갱신 후 잔상 | 남지 않습니다. 주기적 전체 갱신이 필요하지 않았습니다 |
| 충전 유지 및 sleep 미진입 | 꽂아둔 채 잔량이 유지되고, 앱이 앞에 있는 동안 잠들지 않습니다 |

### 앞으로

목표한 범위를 채웠으므로 여기서 일단락합니다. 나중에 다시 손댄다면 처음 구상에 있던 캘린더·일정 표시를 얹는 것이 후보입니다.
